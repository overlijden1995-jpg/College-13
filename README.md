# College-13
A dark edit of College traits 13.0

## Note on `game/archive.rpa`
`game/archive.rpa` (352 MB, the game's scripts) is stored with Git LFS (see `.gitattributes`). GitHub's "Download ZIP" button only includes a small placeholder for LFS files, so the game will not start from the ZIP alone. After downloading, open `game/archive.rpa` on the repo page, click Download, and put the real file in `game/`. Or use `git clone` with Git LFS installed.
